cage.css - a dark css library-

This is a library, made exceptionally for users who are going to build dark theme websites from the get go. Cage contains simple design UI Components which helps the user to fastly create an element and give a design to it. These elements design are muted, light weight and are easy to implement. Unlike Bootstrap, Materialize it doesn't have much of functionality and multiple high frame components. But whatever the small cage has is super simple and is great.

So, pack your bags and get on board to enjoy the journey of a dark library. -cage.css
